This is a great Challenge so that you can review the following properties work using flex:
1. justfiy center: Moves the item on the horizontal axis - *main axis*
2. align-text: Moves the item on the vertical axis - *cross axis*

Can be found in this video: https://www.youtube.com/watch?v=LzMnsfqjzkA
Timestamp: around 4:31:15

Flexbox in the crossaxis actually stretches the content vertically if you don't have height. Align-items by default has the default value of stretch. If your using flexbox and you notice that something is stretching in a weird way you should check align-items property.
